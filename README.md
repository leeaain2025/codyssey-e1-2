# 1. 프로젝트 개요
퀴즈 게임 프로그램을 만들며 클래스를 설계하는 기준을 고민해보는 프로젝트입니다.



# 2. 퀴즈 주제 선정 이유
딥러닝 - 오늘 세션에서 배운 것을 복습할 겸


# 3. 실행 방법
python3 main.py


# 4. 기능 목록
1. 퀴즈 진행: 아래 클래스들을 오케스트레이션 -> QuizGame
2. 퀴즈 생성과 출제: 퀴즈 문제 출력 / 정답과 사용자의 답 비교 -> Quiz
3. 퀴즈 목록 관리: 퀴즈 문항 추가 / 퀴즈 목록 보여주기 -> QuizManager
4. 점수 관리: 퀴즈 풀이 후 점수 반영 / 점수 통보 / 최고 점수 기록 및 갱신 -> ScoreManager



# 5. 파일 구조
- 퀴즈 데이터 파일이 손상되었을 때를 대비한 기본 퀴즈 데이터 `DEFAULT_QUIZ`를 상단에 배치
- json 파일을 읽어들이는 함수와 기록하는 함수를 각각 선언 -> `load_json`, `save_json`
- 반복되는 입력시의 숫자값 체크를 함수로 선언. -> `input_int`
- 퀴즈 목록을 관리하는 `QuizManager` 클래스 선언
- 점수를 관리하는 `ScoreManager` 클래스 선언
- 문항수와 난이도를 결정하면 전체적인 퀴즈 프로그램을 진행하는 `QuizGame` 클래스 선언
- 퀴즈 한개를 생성하는 `Quiz` 클래스 선언
- 전체 프로세스를 제어하는 `main` 함수 선언


# 6. 데이터 파일 설명
    제약사항에는 state.json 파일 하나에 퀴즈 데이터와 점수를 모두 몰아넣게 되어 있지만, 관심사를 분리하는게 좋을 것 같아 아래와 같이 분리하여 저장했습니다.  
    물론 실무에서는 이러한 제약사항을 수정해야 할 필요성을 느끼면 반드시 팀원이나 파트장과 의논을 먼저 거친 후 적용해야 할 것입니다.

    - state.json: 점수
    - quiz.json: 퀴즈 데이터
